## 📁 How It Works

1. Confirm that game services and your selected region are available through official channels.
2. Update the game through its normal launcher before attempting to reconnect.
3. Test whether other online services are reachable from the same PC.
4. Compare Wi-Fi with a wired connection when available, and avoid background downloads during testing.
5. Check whether the game is allowed through Windows Firewall without disabling your security protection.
6. Write down the exact error text, region, time and whether disconnects happen at login or during play.

## ❓ FAQ

**Q: Is high ping an FPS problem?**  
A: No. Ping and packet loss are network symptoms; low FPS is a rendering or system-performance issue.

**Q: Should I disable security software?**  
A: No. Verify allowed connections and permissions without turning off protections.
